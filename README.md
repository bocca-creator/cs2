# BattlePass для CS2

Плагін CounterStrikeSharp: досвід за вбивства суперників (бонус за хедшот),
рівні сезону, щоденні та щотижневі завдання й окремі безкоштовні та преміум-нагороди.
Прогрес і преміум-статус зберігаються за авторизованим SteamID64.

## Встановлення

1. Встановіть CounterStrikeSharp версії, сумісної з `CounterStrikeSharp.API 1.0.370`
   (.NET 10), на сервер CS2.
2. Зберіть проєкт за допомогою .NET 10 SDK:

   ```bash
   dotnet build BattlePass/BattlePass.csproj -c Release
   ```

3. Скопіюйте `BattlePass.dll`, `BattlePass.deps.json` і, за потреби,
   `BattlePass.pdb` з `BattlePass/bin/Release/net10.0/` до
   `game/csgo/addons/counterstrikesharp/plugins/BattlePass/` на сервері.
4. Запустіть сервер. CounterStrikeSharp створить конфігурацію в
   `game/csgo/addons/counterstrikesharp/configs/plugins/BattlePass/BattlePass.json`.
   Налаштуйте нагороди та перезапустіть плагін.

## Налаштування

За замовчуванням вбивство іншого гравця в команді суперників дає 10 XP,
хедшот додає 5 XP, рівень потребує 100 XP, максимум — 50 рівнів.
Повторне вбивство того самого гравця протягом 60 секунд не зараховується.
Вбивства ботів, своїх та себе не зараховуються.

Щоденне завдання: 5 вбивств (+50 XP). Щотижневе: 20 хедшотів (+200 XP).
Можна додавати завдання типу `kills` або `headshots` із власними `Id`,
`Name`, `Type`, `Target` і `Xp`. `Id` має бути унікальним для кожного періоду.
Періоди починаються о 00:00 UTC; тиждень — ISO (понеділок).
XP за завдання нараховується автоматично після завершення.

Нагороди налаштовуються в полі `Rewards` конфігурації. Наприклад:

```json
{
  "Rewards": [
    {
      "Level": 1,
      "Name": "100 кредитів",
      "Premium": false,
      "Command": "css_givecredits {steamid} 100"
    },
    {
      "Level": 1,
      "Name": "500 кредитів",
      "Premium": true,
      "Command": "css_givecredits {steamid} 500"
    }
  ]
}
```

Додайте ці записи в **існуючу** конфігурацію (не замінюйте весь файл
фрагментом вище). `css_givecredits` — лише приклад: команда повинна існувати
на вашому сервері. `{steamid}` замінюється на SteamID64 гравця. Порожня
`Command` позначає нагороду як отриману без видачі предмета. За замовчуванням
`Rewards` порожній, тому перед використанням налаштуйте власні призи.
Одна нагорода може бути на кожному рівні кожної гілки.

Зміна `SeasonId` (лише латинські літери, цифри, `-`, `_`) починає новий сезон:
у кожного сезону окремий файл прогресу, преміум-статус та отримані нагороди.
Зміна `XpPerLevel` чи цілей завдань посеред сезону змінює розрахунок прогресу;
краще робити це разом зі зміною сезону.

## Команди

| Команда | Призначення |
| --- | --- |
| `!bp` | Рівень, XP, преміум-статус і доступні нагороди |
| `!bpquests` | Прогрес щоденних і щотижневих завдань |
| `!bpclaim <рівень> <free\|premium>` | Отримати доступну нагороду один раз |
| `css_bppremium <SteamID64> <on\|off>` | Видати або забрати преміум; серверна консоль чи адміністратор із `@css/generic` |

Команди `css_bp`, `css_bpquests` і `css_bpclaim` також можна вводити в
консолі клієнта. Для преміум-гілки немає платежів: адміністратор сам видає
доступ. Якщо преміум вимкнути, отримані раніше нагороди залишаться отриманими.

Дані зберігаються в `plugins/BattlePass/data/progress-<SeasonId>.json` після
кожної події; зберігайте цю директорію та робіть її резервні копії при
оновленні плагіна. Нагорода записується отриманою **перед** виконанням
серверної команди, щоб після збою не видати її двічі. Якщо зовнішня команда
не існує або завершується з помилкою, перевірте консоль і виправте нагороду
вручну: плагін не може підтвердити виконання команди іншого плагіна.
