# CS2: Battle Pass та Duels

Це вихідний код двох плагінів CounterStrikeSharp на .NET 10. Потрібна версія
CounterStrikeSharp API щонайменше 372 (проєкти збираються з пакетом 1.0.374).

## Збірка

```bash
dotnet build BattlePass/BattlePass.csproj -c Release
dotnet build Duels/Duels.csproj -c Release
dotnet run --project PluginLogic.Tests/PluginLogic.Tests.csproj -c Release
```

Для інсталяції можна зібрати обидва проєкти через `dotnet publish -c Release`.
У відповідних директоріях `bin/Release/net10.0/publish/` є DLL плагіна,
`.deps.json`, `MySqlConnector.dll` та `MenuManagerApi.dll`. Розміщуйте кожен
плагін у власній директорії в `addons/counterstrikesharp/plugins/`. На сервері
має бути встановлено CounterStrikeSharp; MenuManagerCS2 потрібен лише для його
додаткових меню, за його відсутності використовуються меню CounterStrikeSharp.

Плагіни створюють стандартні конфігурації через CounterStrikeSharp. Дані MySQL
можна ввімкнути в секції `Database` відповідної конфігурації, задавши доступ
на самому сервері. За замовчуванням MySQL вимкнений, дані зберігаються в JSON
поруч із конфігурацією плагіна. Зберігайте ці JSON-файли при оновленні сервера.
Для бойового сервера обов'язково налаштуйте режими дуелей, час очікування та
координати арени (якщо ввімкнено телепортацію).

## Battle Pass

`!bp` або `!battlepass` відкриває меню прогресу, завдань і магазину;
`!bptasks` відкриває завдання. Є щоденна, тижнева, місячна та глобальна
ротація завдань, XP за дії й Stars за виконані завдання. Фонове збереження
прогресу налаштовується через `SaveIntervalSeconds` (мінімум 30 секунд);
під час вимкнення плагіна дані також записуються. `!bp_reset confirm` очищує дані для адміністратора
з `@css/root`.

## Duels

`!duel` відкриває вибір режиму й ставить живого гравця в чергу; гравці одного
режиму отримують запрошення. `!leaveduel` виходить із черги,
`!duel_accept`/`!duel_decline` керують запрошенням, `!duelstats` показує
статистику, `!queue` — розмір черги. Статистика зберігається після результату
дуелі та при вимкненні. `!duels_reset confirm` очищує її для адміністратора
з `@css/root`.

Без CS2-сервера перевірено збірку обох проєктів і логіку періодів та підбору
пари; поведінку у грі потрібно перевірити на сервері з CounterStrikeSharp.
